## 速查表

本篇是整套语法的“地图”：把基本语法与扩展语法的全部元素浓缩成两张表，每个元素只给最常用的写法。它不负责讲透，每个元素的完整用法、替代写法和最佳实践，分别在《基本语法》与《扩展语法》逐节展开。建议把本篇收藏起来，写作时忘了某个符号，回来扫一眼就走。

### 2.1 总览

两张表的分工如下：

- **基本语法表**——Markdown 最初设计里就有的元素，几乎所有 Markdown 应用都支持，放心用；
- **扩展语法表**——后来在实践中补充进来的元素，多数主流平台支持，但不是处处可用，用前留意目标应用的支持情况（背景见《入门》的方言一节）。

表里每个元素只列最常用的一种写法；同一元素的第二种写法（比如粗体也可以用双下划线包裹），不进速查表，统一在对应正文节里讲，避免这张“地图”越写越厚。

### 2.2 基本语法表

| 元素 | Markdown 写法 |
| --- | --- |
| 标题 | `# 一级标题`、`## 二级标题`，井号最多六个，井号后要有空格 |
| 粗体 | `**粗体文本**` |
| 斜体 | `*斜体文本*` |
| 引用块 | `> 引用的文字`（行首加大于号） |
| 有序列表 | `1. 第一项`，每项一行，数字加点再加空格 |
| 无序列表 | `- 列表项`，每项一行 |
| 行内代码 | `` `代码` ``（反引号成对包裹） |
| 分隔线 | `---`（单独成行，前后留空行） |
| 链接 | `[显示文字](https://example.com)` |
| 图片 | `![替代文字](https://example.com/图.png)`，本地文件把网址换成相对路径 |

### 2.3 扩展语法表

| 元素 | Markdown 写法 |
| --- | --- |
| 表格 | 用竖线分隔列、用连字符行定义表头（完整示例见下方） |
| 围栏代码块 | 三个反引号上下成对包裹（完整示例见下方） |
| 脚注 | 正文处 `这里有注[^1]`，文末 `[^1]: 注文内容` |
| 标题编号 | `### 节名 {#自定义编号}` |
| 定义列表 | 术语单独一行，下一行以 `: ` 开头写定义 |
| 删除线 | `~~要划掉的文字~~` |
| 任务列表 | `- [ ] 待办事项`、`- [x] 已完成事项` |

两个多行元素的完整形态如下。表格是竖线分列，第二行的连字符把第一行定为表头：

```text
| 姓名 | 城市 |
| --- | --- |
| 老周 | 苏州 |
| 小蒋 | 成都 |
```

渲染效果如下：

| 姓名 | 城市 |
| --- | --- |
| 老周 | 苏州 |
| 小蒋 | 成都 |

围栏代码块是上下各三个反引号，中间的内容会原样显示。完整形态如下（为了让反引号本身显示出来，示例用缩进方式展示，实际书写时反引号顶格写）：

    ```
    print("速查表在手，语法不愁")
    ```

渲染效果如下：

```python
print("速查表在手，语法不愁")
```

再提醒一次：扩展语法并非处处可用。上表里的元素在你的目标平台是否生效，动笔前花一分钟逐个试一遍最稳妥；每个元素的支持情况与细节，《扩展语法》里都会讲。

### 2.4 练习任务

三个任务都只需要一个在线 Markdown 编辑器（《入门》1.3 讲过怎么找）。

**任务一：只靠两张表排版一段白文**

把下面这段没有任何格式的文字，按括号里的要求排成 Markdown，全程只允许翻本篇的两张表：

```text
读书会通知(做成一级标题)
本周共读书目是乡土中国(书名加粗)
时间(做成二级标题)
周六晚八点(做成引用块)
带上这三样(做成无序列表):笔记本、便签、水杯
```

完成标准：预览里标题、粗体、引用、列表全部生效；排版过程中没有翻《基本语法》正文，只用了 2.2 的表。

**任务二：验证你常用平台的扩展语法支持**

把 2.3 表里的七个元素逐个敲进你最常用的一个支持 Markdown 的应用（笔记软件、博客后台都行），记录每个元素是否生效。

完成标准：得到一份七行的“支持清单”，并能据此说出你的平台大致属于《入门》1.6 里说的哪种情况。

**任务三：做一张你自己的高频卡**

从两张表里挑出你日常最可能用到的五个元素，新建一个 `我的速查卡.md`，按“元素加写法”各写一行，并给每个元素配一个自己的例子。

完成标准：文件保存后重新打开，五个元素里不看本篇也能默写出三个以上的写法。

### 2.6 新手常见问题

**Q1：速查表需要背下来吗？**

不需要。它的定位就是“忘了就查”；高频元素写多了自然记住，低频的永远可以回来翻。

**Q2：我见过用星号开头的无序列表、用双下划线写的粗体，和表里的写法不一样，谁对？**

都对。不少元素有两种以上写法，速查表只收最常用的一种，替代写法在《基本语法》对应节里讲；同一份文档里保持一种风格就好。

**Q3：为什么扩展语法表比基本语法表短，功能看起来反而更专？**

基本语法覆盖的是文章骨架（标题、段落、列表这些），扩展语法补的是专项能力（表格、脚注、任务列表这些）。条数少不代表不重要，只是它们各管一个具体场景。

**Q4：表里的写法我照抄了还是不生效，怎么办？**

先检查细节：井号、数字点号后面要有空格，符号要用半角。细节都对还不生效，多半是平台不支持该元素（尤其扩展语法），对照《入门》1.6 的方言一节判断属于哪种情况。
