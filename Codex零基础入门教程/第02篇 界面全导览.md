## 界面全导览

上一篇《认识与装好》里已经完成安装，并让 Codex 运行了几个简单任务。这一篇暂时不学习复杂功能，先熟悉应用的主要界面。

了解这些区域和入口之后，你会更容易判断应该在哪里新建任务、如何向 Codex 提供文件，以及到哪里查看执行过程和文件改动。现在不需要记住所有按钮，先建立整体印象，再通过后面的练习加深理解。

### 2.1 界面的五个主要区域

打开应用并切换到 Codex 视图，可以把界面大致分成五个区域：

1. **左侧边栏**：显示对话列表、项目列表、搜索框和设置入口。

2. **中间对话区**：用于查看你与 Codex 的对话，以及任务执行过程。

3. **输入区域**：用于输入和发送消息，也包含附件、@ 提及、斜杠命令和模型选择等功能。

4. **侧边预览区**：用于显示浏览器、后台任务和文件改动等内容。

5. **顶部工具区**：包含新建对话、终端等常用入口。

![ep2-01.png](img/02/ep2-01.png)



这五个区域暂时不必逐项记忆。阅读后面的内容时，可以不时回到这张总览图，确认相关功能位于哪里。

### 2.2 项目就是 Codex 工作的文件夹

这一篇最重要的概念是：**Codex 中的项目，本质上就是电脑中的一个文件夹。**

- 选择哪个项目，Codex 就主要在哪个文件夹中执行任务。

- 任务生成的文件和中间结果通常会保存在这个文件夹中。

- 新建空白项目时，应用会创建一个新的文件夹；你也可以把电脑中已有的文件夹添加为项目。

![ep2-02](img/02/ep2-02.png)

如果想确认项目在电脑中的实际位置，可以在项目名称上单击右键，选择 **在资源管理器中打开**。应用中的项目和资源管理器中的文件夹，是同一个位置的两种显示方式。

![ep2-02-1](img/02/ep2-02-1.png)

建议按照工作内容划分项目。例如，整理一批照片、制作一份活动方案和分析一张销售表，可以分别建立不同的项目。这样文件更容易管理，对话内容也不容易互相干扰。

#### 普通对话和项目对话有什么区别

两者最直接的区别，是有没有指定工作的文件夹。

- **普通对话**：没有关联项目，适合提问、讨论思路和测试提示词。

- **项目对话**：关联了项目文件夹，适合读取、修改文件并交付实际成果。

可以简单理解为：只需要讨论问题时，不关联项目也可以；如果希望 Codex 生成或修改文件，最好先进入对应项目。

如果不小心在普通对话中发送了文件处理任务，也不需要担心。新建一个关联项目的对话，再把需求发送一次即可。

### 2.3 向 Codex 提供文件的三种方式

要让 Codex 处理文件，首先需要让它知道文件在哪里。常用方式有三种。

**方式一：拖入对话框**

可以把文件或文件夹直接拖到对话框中。这种方式最直观，适合临时提供一批需要查看或处理的资料。

![ep2-05.png](img/02/ep2-05.png)



**方式二：通过加号添加附件**

单击输入框旁边的加号，从菜单中选择需要添加的文件。文件所在位置比较深，或者当前不方便拖动窗口时，可以使用这种方式。

加号菜单中还可能包含终端等其他入口，后续课程需要时会再介绍。

![ep2-06](img/02/ep2-06.png)



**方式三：使用 @ 提及**

在输入框中输入 `@`，可以从列表中选择项目里的特定文件。需要明确告诉 Codex“只处理这个文件”时，这种方式比较方便。

`@` 还可以用于调用浏览器、插件或技能。现在先记住它可以选择文件，其他用途在后面的实际任务中再学习。

![ep2-07](img/02/ep2-07.png)

需要注意的是，把一个文件夹拖进对话框，并不等于把它设为当前项目：

- 拖入文件夹，是把资料提供给 Codex 查看。

- 选择项目，是确定 Codex 当前主要工作的文件夹。

第 2.7 节会通过一个小任务演示两者的区别。

### 2.4 如何查看任务执行过程

**任务过程与结果显示**

Codex 执行任务时，会显示它正在读取哪些文件、运行哪些命令，以及修改了哪些内容。界面通常也提供精简显示选项，让你只看主要结果。

刚开始使用时，建议保留任务过程。即使暂时看不懂所有内容，也可以观察它如何拆分任务、在哪一步请求授权，以及最后生成了哪些文件。熟悉以后，再根据需要切换为简洁显示。

![ep2-08](img/02/ep2-08.png)

**终端输出**

运行命令时，界面可能出现一段终端输出。新手不需要逐行理解这些内容。如果任务报错，可以直接让 Codex 阅读错误信息并继续排查；需要人工协助时，也可以把报错内容或截图提供给它。

**同时运行多个对话**

Codex 可以同时处理多个互相独立的对话。例如，一个对话正在整理文件时，可以新建另一个对话处理其他任务。每个任务的状态可以在后台任务区域查看。

**并行运行适合彼此独立的工作。如果两个任务会同时修改同一批文件，最好依次执行，避免产生冲突。**

![ep2-09](img/02/ep2-09.png)



**管理对话**

在对话上单击右键，可以看到置顶、重命名、归档和删除等操作。

- 经常使用的对话可以置顶。

- 完成后暂时不再使用的对话可以归档。

- 已归档的对话可以在“设置 → 已归档对话”中找回。

![ep2-10](img/02/ep2-10.png)



**统一搜索**

侧边栏中的搜索框可以帮助你查找以前的对话和项目内容。随着对话数量增加，使用关键词搜索通常比逐个翻找更方便。

![ep2-11](img/02/ep2-11.png)



### 2.5 常见工作面板

下面先简单认识几个常见面板。现在只需要知道它们的用途，不必马上掌握所有操作。

- **Diff 改动面板**：显示 Codex 对文件做了哪些修改。通常用红色表示删除、绿色表示新增，也可以在这里进一步检查内容。

- **集成终端**：可以从顶部工具区或加号菜单打开，用于运行命令。后续安装工具和配置功能时会用到。

- **侧边预览区**：浏览器、后台任务和部分预览内容会显示在这里。

- **插件面板**：用于查看和使用已经安装的插件。

- **已安排面板**：用于管理定时或重复运行的任务。

- **宠物入口**：用于启用桌面宠物等外观与辅助功能。

### 2.6 设置中的常用选项

设置页面集中管理 Codex 的权限、工具和界面配置。以下选项与后续课程关系较为密切：

- **常规 → 权限**：设置默认权限、自动审核和完全访问权限，决定 Codex 可以执行哪些操作。

- **浏览器**：管理 Codex 内置浏览器及其相关功能。

- **使用情况和计费**：查看当前用量、点数余额及限额重置时间。

- **宠物**：选择、显示、收起或调整桌面宠物。

- **已归档任务**：查看、搜索和恢复以前归档的任务。

### 2.9 新手常见问题

**Q1：项目文件夹使用中文名称会有问题吗？**

日常使用通常没有问题。少数较旧的工具可能无法正确处理中文路径。如果遇到原因不明的路径报错，可以把测试项目移到纯英文路径后重试。

**Q2：一个项目可以关联多个文件夹吗？**

项目本身对应一个主要文件夹。如果需要查看其他文件夹中的资料，可以把它拖入对话；如果任务需要同时修改多个相关文件夹，也可以将它们共同的上层文件夹设为项目。操作前应确认项目范围内没有不希望被修改的重要文件。

**Q3：对话越来越多，应该怎样整理？**

可以采用三个简单习惯：一个相对独立的任务使用一个对话，完成后及时归档，需要查找旧内容时使用搜索。任务之间没有关系时，新建对话也有助于减少上下文干扰。

**Q4：删除对话后，生成的文件会一起消失吗？**

不会。对话记录和项目文件是两类内容。生成的文件保存在项目文件夹中，删除对话不会自动删除磁盘中的文件。

**Q5：后台任务运行时，可以关闭应用吗？**

如果任务依赖当前电脑和桌面应用，关闭应用可能会中断运行。处理较长任务时，建议保持应用开启，并根据需要打开防休眠。云端任务和自动化任务的运行方式会在后续课程中单独介绍。
